# 全息烛台 · Holographic Candlestick

基于 **MediaPipe 手势识别 + Three.js** 的 3D 全息烛台交互界面。烛台悬浮在操作者面前，摄像头画面全屏作为背景，通过双手手势实时缩放与移动；摄像头不可用时自动切换鼠标控制。

![预览](assets/preview.jpg)

## 功能特性

- 摄像头画面全屏展示，置于**纯黑底**之上，**视频透明度（可见度）可调**——调到 0% 即纯黑背景 + 全息烛台
- **双手张合 → 缩放**（以两掌间距为标尺，并跟随双手中心）
- **双手同时捏合 → 精细缩放**（拇指＋食指，防抖迟滞）
- **单掌张开 → 左右上下移动**烛台
- **鼠标兜底控制**：摄像头无法访问 / 手势模型加载失败时自动启用，也可手动切换
  - 左键拖拽 → 移动 · 滚轮 → 缩放 · 右键拖拽 → 旋转 · 双击 → 重置
- 手势骨骼点叠加显示（可开关）
- 全息扫描线 / 浮动静止波段 / fresnel 边缘光着色器
- 全息亮度、火焰呼吸、悬浮粒子、地面光环、投影锥
- 左上角遥测文本框（带状态小点）：CAM 相机 · MODEL 手势模型 · HANDS 手数 · FPS 帧率 · MODE 模式
- 重置视角（`R` 键或按钮）、手势/鼠标模式切换（`M` 键）、浏览器全屏切换
- 依赖多镜像 CDN 自动回退（jsDelivr → fastly → npmmirror），国内网络可用

## 手势说明

| 手势 | 效果 |
| --- | --- |
| 双手张开（两掌间距） | 放大缩小烛台，跟随双手中心 |
| 双手同时捏合（拇指＋食指） | 精细缩放烛台 |
| 单掌张开（四指伸直） | 烛台随手掌左右、上下移动 |
| 其他姿势 / 无手 | 待命，烛台自动缓慢旋转 |

## 鼠标控制说明

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 移动烛台 |
| 滚轮 | 放大 / 缩小 |
| 右键拖拽 | 旋转视角（限位 ±66°） |
| 双击 / `R` | 重置视角 |

## 运行方式

直接双击打开 `index.html` 即可运行（需联网加载 CDN 资源，并允许浏览器使用摄像头）。

建议部署到 GitHub Pages / HTTPS 环境——摄像头 API（getUserMedia）在安全上下文中最稳定。

## 技术栈

- **MediaPipe Hands**（legacy solutions）：21 点手部关键点实时跟踪，模型与 WASM 随 npm 包分发，可走国内镜像
- **Three.js r128**：WebGL 全息渲染（自定义 ShaderMaterial，加色混合）
- **原生 JavaScript**：无构建步骤，单文件自包含

## 部署到 GitHub Pages

1. 新建仓库，将本目录文件推送到仓库根目录（`index.html` 必须在根目录）
2. 仓库 **Settings → Pages → Source** 选择分支 `main` / 根目录
3. 访问 `https://<用户名>.github.io/<仓库名>/`

## 注意事项

- 首次加载需下载手势模型与 WASM（合计约 12MB），首次运行请稍候
- 摄像头权限：Chrome / Edge 直接打开本地文件通常可用；若被拦截，请用本地静态服务器或部署到 GitHub Pages 后访问
- 无摄像头权限 / 手势模型加载失败时，自动进入**鼠标控制模式**，全息烛台与 UI 照常渲染
